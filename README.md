# 📘 Manual de Buenas Prácticas para Trabajos Universitarios en Grupo

## 📝 Descripción
Este repositorio contiene el manual colaborativo creado para la materia de Diplomado. Recopila las mejores estrategias para organizar, redactar y presentar trabajos en equipo, utilizando Git y GitHub como herramienta de gestión de versiones.

## 📂 Estructura del Proyecto
- `/documentos` - Contiene el manual en formato Markdown (.md) y la versión en PDF.
- `/imagenes` - Gráficos, ejemplos de formatos o capturas de pantalla.
- `/referencias` - Archivos de fuentes bibliográficas (PDFs o enlaces).
- `/plantillas` - Plantillas de portada, índices o checklists.

## 🚀 Cómo contribuir
1. Cada miembro trabaja en su propia **rama**.
2. Hacer Pull Requests (PR) para fusionar los cambios.
3. Revisar el trabajo de los compañeros antes de aprobar el PR.
